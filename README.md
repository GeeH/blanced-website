# Blanced website

Static site for [blanced.co.uk](https://blanced.co.uk), served by GitHub Pages.

## Styles

The CSS is built with Tailwind into `public/css/styles.css`, which is committed. After adding or changing Tailwind classes in any HTML file, rebuild it:

```
npm install
npm run build:css
```

Use `npm run watch:css` to rebuild automatically while editing.
